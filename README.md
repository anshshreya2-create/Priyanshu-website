# Priyanshu Student Portfolio

A responsive static website built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — website content
- `style.css` — styling and mobile layout
- `script.js` — mobile navigation and current year

## Run locally
Open `index.html` in a browser. For best results, use a simple local server or a code editor with live preview.

## Publish on GitHub Pages
1. Create a public repository on GitHub.
2. Upload all three website files (`index.html`, `style.css`, and `script.js`) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the published URL to appear in the Pages settings.

## Publish on Vercel
1. Upload the files to a GitHub repository.
2. Sign in to Vercel using GitHub and import the repository.
3. Keep the framework preset as **Other** (or leave auto-detected settings), with no build command and no output directory needed for this static site.
4. Click **Deploy**.
